📅 Vooruit plannen

Voor — kies een datum en eventueel een korte notitie. Alleen een beheerder kan hier toestellen goedkeuren of intrekken.

Zet de app op slot voor onbekende toestellen: genereer een code en geef die door aan iemand op een nieuw toestel (bv. een extra telefoon). Zonder goedgekeurd toestel + code kan de lijst daar niet geopend worden — je eigen toestel hier wordt automatisch goedgekeurd.

Nog geen andere toestellen goedgekeurd. Zodra je hierboven een code genereert en iemand die op een nieuw toestel invoert, verschijnt het hier.

WhatsApp-melding bij lang blijven liggen

Alleen een beheerder kan dit instellen.

Stuurt automatisch een WhatsApp-appje zodra iets het ingestelde aantal dagen op rij (zie Zaak) blijft liggen (hoogstens één keer per dag per product) — als extra kanaal naast (of in plaats van) Telegram hieronder. Werkt via de gratis dienst CallMeBot: stuur "I allow callmebot to send me messages" naar +34 684 734 044 in WhatsApp (check bij twijfel callmebot.com voor het actuele nummer) — je krijgt dan een apikey terug per WhatsApp. Let op: CallMeBot geeft geen bevestiging terug of een bericht ook echt is aangekomen, en kan af en toe zonder waarschuwing stoppen.

Telegram-melding bij lang blijven liggen

Alleen een beheerder kan dit instellen.

Stuurt automatisch een Telegram-berichtje zodra iets het ingestelde aantal dagen op rij (zie Zaak) blijft liggen (hoogstens één keer per dag per product) — kan gewoon naast WhatsApp hierboven aanstaan; geeft (anders dan CallMeBot) wel een echte foutmelding terug als er iets misgaat. Werkt via een eigen, gratis Telegram-bot: app in Telegram met @BotFather, stuur "/newbot" en volg de stappen — je krijgt dan een bot-token terug. Stuur daarna zelf een bericht naar je nieuwe bot, zodat je chat-ID kan worden opgezocht (bv. via api.telegram.org/bot<token>/getUpdates). Vul beide hieronder in.
