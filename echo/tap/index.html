Box op tafel

De bediening tikt na het afrekenen het tafelnummer in, controleert het bedrag van de rekening en zet de box op tafel. De gast tikt een gezichtje. Echo koppelt de stem aan de rekening van die tafel.

Box installeren

Installeren werkt alleen in Chrome of Edge op een laptop of pc. Open deze pagina daar.
1
Aansluiten

Sluit de box met een USB-C-datakabel aan op deze laptop.

De box heeft twee chips achter één poort. Welke je ziet hangt af van hoe de stekker erin zit. Kies straks USB JTAG/serial debug unit. Zie je die niet, of zegt hij dat het een "ESP32" is in plaats van een "ESP32-S3"? Draai de USB-C-stekker dan om.
2
Software op de box zetten

Eén keer nodig per box, of als er een nieuwe versie is. Duurt ongeveer een minuut.

Deze browser kan geen box installeren. Gebruik Chrome of Edge. Open deze pagina via https.

3
Wifi en zaak instellen

De box werkt alleen op 2,4 GHz-wifi en niet op een gastnetwerk met inlogpagina. Het wachtwoord blijft op de box en gaat niet naar Echo.
